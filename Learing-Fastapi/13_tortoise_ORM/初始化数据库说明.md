### 1.初始化配置，只需要使用一次
- aerich init -t settings.TORTOISE_ORM #TORTOISE_ORM配置的位置
- 初始化完成会在当前目录生成一个问及那： pyproject.tmol 和一个文件夹: migrations
- pyproject.tmol ： 保存配置文件路径
- migrations： 存放迁移文件
- 注意： 记得配 aerich.models

### 2.初始化数据库，一般情况下只用一次
aerich init-db
- 1. 此时数据库中就有响应的表格、
- 2. 如果TORTOISE_ORM配置文件中的models改了名，则执行这条命令时需要增加--app参数，来指定你修改的名字

### 3.如果模型类更新了，如何同步更新到数据库
- aerich migrate [--name] （标记修改操作说明，可以不填）
- 1. 新版使用的是.py文件，若要生成纯sql文件可用：aerich init-db --format sql
- 2. 或者配置 ：[aerich]
- migrate_format = sql  # 强制使用 SQL 格式
- 
- ### 4. 还要进行最后的重新执行迁移，才会写入数据库
- aerich upgrade
- 还支持回退操作：  aerich downgrade
